No wallet installed at all?

A wallet is what actually holds and sends the money — PayTag never touches your funds. It takes about a minute:

  1. Install Phantom (browser extension on a computer, or the app on a phone).
  2. Add a little SOL, or USDC if this link asks for it.
  3. Come back and scan the code above, or tap "Connect Wallet to Pay".

Payments powered by Solana. Nothing is stored on a server.
